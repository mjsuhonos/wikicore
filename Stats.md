# WikiCore Statistics Documentation

This document explains the statistics generated by the `make stats` target and what they illustrate about the WikiCore corpus.

## Overview

The `make stats` target generates a TSV file (`stats.tsv`) containing statistics about the WikiCore JSONL files. Statistics are organized in rows with a `subject` column that identifies the aggregation level:

- **`__overall__`**: Aggregated statistics for all documents across all categories and splits
- **`__category__*`**: Statistics grouped by category (core, class, occupation, unmapped)
- **subject names**: Statistics for each individual subject (e.g., `class/aircraft`, `occupation/medicine`)

All rows contain the same 14 columns, allowing for easy comparison across different slices of the data.

## Output Format

The output is a TSV file with the following columns:

```
subject	total_documents	unique_qids	qids_with_wikipedia	documents_with_2_plus_paragraphs	total_paragraphs	avg_paragraphs_per_document	documents_with_links	total_links	unique_linked_qids	avg_links_per_document	avg_text_length_chars	avg_links_per_paragraph	avg_links_per_1000_chars
```

## TSV Columns Explained

| Column | Description | What it illustrates |
|--------|-------------|-------------------|
| `subject` | Identifier: `__overall__`, `__category__*`, or subject name | Aggregation level |
| `total_documents` | Total number of documents | Size of the corpus slice |
| `unique_qids` | Number of unique Wikidata QIDs | Deduplication rate (should be close to total_documents) |
| `qids_with_wikipedia` | Number of documents with English Wikipedia articles | Coverage of English Wikipedia |
| `documents_with_2_plus_paragraphs` | Number of documents with 2 or more paragraphs | Documents with meaningful content depth |
| `total_paragraphs` | Total number of paragraphs across all documents | Total text volume in paragraphs |
| `avg_paragraphs_per_document` | Average number of paragraphs per document | Typical document length |
| `documents_with_links` | Number of documents with at least one link | How many documents reference other entities |
| `total_links` | Total number of link occurrences | Overall connectivity in the knowledge graph |
| `unique_linked_qids` | Number of unique QIDs referenced in links | Size of the knowledge graph (out-degree) |
| `avg_links_per_document` | Average number of links per document | Typical out-degree |
| `avg_text_length_chars` | Average document text length in characters | Typical document size |
| `avg_links_per_paragraph` | Average number of links per paragraph | How densely linked paragraphs are |
| `avg_links_per_1000_chars` | Average number of links per 1000 characters | Link density normalized by text length |

## Categories and Subjects

### Categories

The corpus is organized into three main categories:

1. **core**: Core Wikipedia concepts (not specific to class or occupation)
2. **class**: Documents organized by class (e.g., aircraft, building, city)
3. **occupation**: Documents organized by occupation (e.g., medicine, law, engineering)
4. **unmapped**: Documents without Wikidata entries (filtered out during processing)

### Subjects

Each category contains multiple subjects. For example:
- `class/aircraft`: All aircraft-related documents
- `class/building`: All building-related documents
- `occupation/medicine`: All medicine-related documents

Subjects aggregate statistics across all splits (train, eval, test), providing a complete picture of each topic area.

## Example Use Cases

### 1. Understanding Corpus Composition

The overall statistics show:
- 6.1M total documents
- 5.4M unique QIDs (some QIDs appear in multiple splits)
- All documents have Wikipedia articles (100% coverage)
- Average of 1.59 paragraphs per document (typical Wikipedia article introduction)
- 32% of documents have 2+ paragraphs
- 49% of documents have at least one link
- Average of 0.94 links per document
- Average document length: 444 characters

### 2. Comparing Categories

- **Class** category has the most documents (3.5M) with moderate linking (1.10 links/doc)
- **Core** documents have the longest average text (810 chars) and lowest link density
- **Occupation** documents tend to have slightly longer intros (1.61 avg paragraphs) but lower link density

### 3. Analyzing Link Patterns

- About half of documents (3M out of 6.1M) have at least one link
- Total of 5.8M link occurrences
- These links reference 245K unique QIDs
- Average link density: 0.59 links per paragraph, 2.12 links per 1000 characters

### 4. Finding High-Quality Subjects

Subjects with high `documents_with_2_plus_paragraphs` and high `avg_links_per_document` tend to have more comprehensive, well-connected articles. For example:
- `class/aircraft`: 37% of documents have 2+ paragraphs, 1.18 avg links/doc
- `class/city`: 39% of documents have 2+ paragraphs, 1.43 avg links/doc
- `occupation/politics`: 34% of documents have 2+ paragraphs, 0.80 avg links/doc

## Running Statistics

To generate statistics:

```bash
# For a specific date
RUN_DATE=20260914 make stats

# For today's date (default)
make stats

# Or run the script directly
python3 stats.py wikicore-20260914-en source.nosync > stats.tsv
```

The output will be saved to `$(OUT_DIR)/stats.tsv`.

## Output Format Notes

- The TSV format allows for easy import into spreadsheets or data visualization tools
- The `subject` column uses prefixes to distinguish aggregation levels:
  - `__overall__`: Total across all data
  - `__category__*`: Aggregated by category
  - Plain subject names: Individual subject statistics
- All numeric values are tab-separated
- Header row contains column names for easy parsing
