# WikiCore Statistics Documentation

This document explains the statistics generated by the `make stats` target and what they illustrate about the WikiCore corpus.

## Overview

The `make stats` target generates a comprehensive JSON file (`stats.json`) containing statistics about the WikiCore JSONL files. Statistics are organized at three levels:

1. **Overall**: Aggregated statistics for all documents across all categories and splits
2. **By Category**: Statistics grouped by category (core, class, occupation, unmapped)
3. **By Subject**: Statistics for each individual subject (e.g., `class/aircraft`, `occupation/medicine`)

Each level contains the same set of metrics, allowing for easy comparison across different slices of the data.

## Output Structure

```json
{
  "overall": { ... },
  "by_category": {
    "core": { ... },
    "class": { ... },
    "occupation": { ... },
    "unmapped": { ... }
  },
  "by_subject": {
    "core": { ... },
    "class/aircraft": { ... },
    "class/astronomy": { ... },
    "occupation/medicine": { ... },
    ...
  },
  "metadata": {
    "total_subjects": 61,
    "total_files_processed": 183,
    "unmapped_count": 0
  }
}
```

## Statistics Explained

### Document Counts

| Field | Description | What it illustrates |
|-------|-------------|-------------------|
| `total_documents` | Total number of documents in the corpus | Size of the corpus |
| `unique_qids` | Number of unique Wikidata QIDs | Deduplication rate (should be close to total_documents) |
| `qids_with_wikipedia` | Number of documents with English Wikipedia articles | Coverage of English Wikipedia |

### Paragraph Statistics

| Field | Description | What it illustrates |
|-------|-------------|-------------------|
| `total_paragraphs` | Total number of paragraphs across all documents | Total text volume in paragraphs |
| `avg_paragraphs_per_document` | Average number of paragraphs per document | Typical document length |
| `median_paragraphs_per_document` | Median number of paragraphs per document | Central tendency (less affected by outliers) |
| `documents_with_2_plus_paragraphs` | Number of documents with 2 or more paragraphs | Documents with meaningful content depth |
| `paragraphs_histogram` | Distribution of paragraph counts (`1`, `2-3`, `3-5`, `5+`) | Distribution of document lengths |

**Example Interpretation**: If `avg_paragraphs_per_document` is 1.59, most Wikipedia articles in the corpus have 1-2 paragraphs (the introduction). A higher average indicates more comprehensive articles.

### Link Statistics

| Field | Description | What it illustrates |
|-------|-------------|-------------------|
| `documents_with_links` | Number of documents with at least one link | How many documents reference other entities |
| `total_links` | Total number of link occurrences | Overall connectivity in the knowledge graph |
| `unique_linked_qids` | Number of unique QIDs referenced in links | Size of the knowledge graph (out-degree) |
| `avg_links_per_document` | Average number of links per document | Typical out-degree |
| `median_links_per_document` | Median number of links per document | Central tendency of out-degree |
| `p50_links`, `p95_links`, `p99_links` | 50th, 95th, 99th percentiles of links per document | Distribution of link density |
| `link_thresholds` | Counts of documents with >N links for N=0,1,2,3,5,10,20 | Link density distribution |
| `links_histogram` | Distribution of link counts (`0-1`, `1-5`, `5-10`, `10-20`, `20+`) | Link density categories |

**Example Interpretation**: 
- `p50_links` (median) of 0 means at least half of all documents have no links
- `p95_links` of 3 means 95% of documents have 3 or fewer links
- The `>0` threshold shows how many documents have at least one link
- A high `unique_linked_qids` relative to `total_links` indicates diverse references

### Text Length Statistics

| Field | Description | What it illustrates |
|-------|-------------|-------------------|
| `avg_text_length_chars` | Average document text length in characters | Typical document size |
| `median_text_length_chars` | Median document text length in characters | Central tendency of document size |
| `text_length_histogram` | Distribution of text lengths (`0-500`, `500-1000`, `1000-5000`, `5000+`) | Document size categories |

**Example Interpretation**: An average text length of 444 characters indicates relatively short introductory paragraphs, typical for Wikipedia article intros.

### Link Density Statistics

| Field | Description | What it illustrates |
|-------|-------------|-------------------|
| `avg_links_per_paragraph` | Average number of links per paragraph | How densely linked paragraphs are |
| `avg_links_per_1000_chars` | Average number of links per 1000 characters | Link density normalized by text length |

**Example Interpretation**: These metrics show the information density of the corpus. Higher values indicate more interconnected content.

## Categories and Subjects

### Categories

The corpus is organized into three main categories:

1. **core**: Core Wikipedia concepts (not specific to class or occupation)
2. **class**: Documents organized by class (e.g., aircraft, building, city)
3. **occupation**: Documents organized by occupation (e.g., medicine, law, engineering)
4. **unmapped**: Documents without Wikidata entries (filtered out during processing)

### Subjects

Each category contains multiple subjects. For example:
- `class/aircraft`: All aircraft-related documents
- `class/building`: All building-related documents
- `occupation/medicine`: All medicine-related documents

Subjects aggregate statistics across all splits (train, eval, test), providing a complete picture of each topic area.

## Example Use Cases

### 1. Understanding Corpus Composition

```json
{
  "overall": {
    "total_documents": 6128847,
    "unique_qids": 5444953,
    "qids_with_wikipedia": 6128847
  }
}
```

This shows:
- 6.1M total documents
- 5.4M unique QIDs (some QIDs appear in multiple splits)
- All documents have Wikipedia articles (100% coverage)

### 2. Comparing Categories

```json
{
  "by_category": {
    "core": {
      "total_documents": 865369,
      "avg_paragraphs_per_document": 1.55
    },
    "class": {
      "total_documents": 3521671,
      "avg_paragraphs_per_document": 1.59
    },
    "occupation": {
      "total_documents": 1741807,
      "avg_paragraphs_per_document": 1.61
    }
  }
}
```

This shows:
- Class category has the most documents (3.5M)
- Occupation documents tend to have slightly longer intros (1.61 avg paragraphs)

### 3. Analyzing Link Patterns

```json
{
  "overall": {
    "documents_with_links": 3030892,
    "total_links": 5772352,
    "unique_linked_qids": 245443,
    "avg_links_per_document": 0.94,
    "p95_links": 3.0
  }
}
```

This shows:
- About half of documents (3M out of 6.1M) have at least one link
- Total of 5.8M link occurrences
- These links reference 245K unique QIDs
- 95% of documents have 3 or fewer links (p95 = 3)

### 4. Finding High-Quality Subjects

Subjects with high `documents_with_2_plus_paragraphs` and high `avg_links_per_document` tend to have more comprehensive, well-connected articles.

## Running Statistics

To generate statistics for existing data:

```bash
# For a specific date
RUN_DATE=20260914 make stats

# For today's date (default)
make stats

# Or run the script directly
python3 stats.py wikicore-20260914-en source.nosync > stats.json
```

The output will be saved to `$(OUT_DIR)/stats.json`.

## Implementation Notes

- The `unmapped` category contains documents that were filtered out during processing (no Wikidata entry). In most cases, this count will be 0 or very small.
- All statistics for `unmapped` documents are 0 since they lack the structured metadata.
- Percentiles are calculated using linear interpolation for smoother estimates.
- Histograms use simple binning with the last bin being open-ended (e.g., `20+` means 20 or more).
- Link thresholds show cumulative counts: `>0` means documents with 1+ links, `>1` means documents with 2+ links, etc.
